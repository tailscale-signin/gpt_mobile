# gpt_mobile

Android GPT Mobile Client.

## Releases & Downloads

Pre-built APK artifacts are generated and attached to [GitHub Releases](https://github.com/tailscale-signin/gpt_mobile/releases).

### Building APK locally

To build the APK locally:

```bash
./gradlew assembleRelease
# or debug build
./gradlew assembleDebug
```

The generated APK can be found at:
`app/build/outputs/apk/debug/app-debug.apk` or `app/build/outputs/apk/release/app-release.apk`.
